# Linux Security Checker

A Bash-based cybersecurity tool developed for the **IqraSec Academy Cybersecurity Scripting & Automation Internship — Phase 1**.

## Objective

The Linux Security Checker performs basic security checks on a Linux system and presents the results in a clear terminal-based format.

The tool is designed to demonstrate practical Bash scripting, Linux administration, cybersecurity awareness, command-line argument handling, and basic error handling.

## Features

- Displays current user and privilege status
- Displays operating system information
- Displays kernel version and system architecture
- Checks listening TCP and UDP ports
- Checks firewall availability and status
- Checks SSH server configuration
- Checks for failed login attempts
- Checks common temporary directories for world-writable files
- Supports command-line arguments
- Includes a built-in help/usage option
- Handles missing commands, files, and security utilities

## Requirements

- Linux operating system
- Bash
- Standard Linux utilities
- Root/sudo privileges recommended for complete results

### Tested Environment

- Kali GNU/Linux Rolling
- Bash
- x86_64 architecture
